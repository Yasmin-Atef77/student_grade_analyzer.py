# Student Grade Analyzer

## Overview
A beginner Python project that analyzes student records and calculates basic grade statistics using nested dictionaries and loops.

## Features
- **Display Student Scores:** Prints each student's name and score.
- **Highest-Scoring Student:** Identifies the student with the highest score.
- **Average Score:** Calculates the average score of all students.

## Technologies Used
- Python
- Dictionaries and nested dictionaries
- `for` loops
- Conditional statements
- Basic arithmetic

## What I Learned
- Accessing data stored in nested dictionaries.
- Iterating through dictionary items using `.items()`.
- Comparing values to find the highest score.
- Calculating an average using `len()` and arithmetic operations.

## Example Output

Mona 92

Highest student: Sara
95
